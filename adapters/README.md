# 平台适配器

> 钱喵 AI 财务助手的引擎层是纯 Markdown 指令，可在任何支持系统指令的 AI 平台上运行。本目录提供各平台的适配指南。

## 通用适配原则

1. **引擎完整加载**：将 `core/` 下全部 5 个文件（或 `SYSTEM-FULL.md` 合并版）粘贴到系统指令区域
2. **经验包作为知识**：将经验包文件上传到平台的知识库/文档库，或在对话中提供
3. **数据脱敏由用户负责**：无论哪个平台，数据脱敏责任都在用户

## 目录

| 文件 | 平台 | 说明 |
|------|------|------|
| `qianfan.md` | 百度千帆 | 推荐平台，原生中文支持 |
| `generic.md` | 通用平台 | ChatGPT / Claude / Gemini 等 |

## 适配器内容

各适配器文件包含：
- 平台特性说明
- 引擎加载方式
- 经验包加载方式
- 已知限制和注意事项
- 验证步骤
