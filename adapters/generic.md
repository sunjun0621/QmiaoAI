# 通用平台适配

> 适用于 ChatGPT、Claude、Gemini 等支持系统指令的 AI 平台。

## 适用平台

| 平台 | 系统指令支持 | 知识库 | 文件上传 |
|------|-------------|--------|----------|
| ChatGPT (GPT-4) | Custom Instructions | 支持 | 支持 |
| Claude (Anthropic) | System Prompt | 支持 | 支持 |
| Gemini (Google) | System Instructions | 支持 | 支持 |
| 其他兼容平台 | 需验证 | - | - |

## 引擎加载

### 方式 A：使用全量合并版

将 `core/SYSTEM-FULL.md` 全部内容粘贴到平台的系统指令/自定义指令区域。

### 方式 B：按顺序拼接

按以下顺序拼接 5 个文件后粘贴：

1. `core/SYSTEM.md`
2. `core/PACK_LOADER.md`
3. `core/RULE_SCANNER.md`
4. `core/GATE.md`
5. `core/REF_SYNTAX.md`

## 经验包加载

### 方式 A：文件上传

将经验包文件上传到对话中，AI 在会话期间可引用。

### 方式 B：对话中粘贴

首次对话时将 L1 规则和 L2 模板内容粘贴到对话中。

### 方式 C：知识库/文档库

如果平台支持知识库功能，将经验包文件上传到知识库并关联。

## 数据输入

- 支持 CSV、纯文本格式
- 平台支持文件上传时可直接上传
- 不支持文件上传时在对话中粘贴

## 注意事项

### 语言设置

- 指令使用中文编写，部分平台可能需要设置语言偏好为中文
- 英文平台的 System Prompt 可能需要添加"请用中文回复"指令

### 上下文窗口

- 长报告生成时注意上下文长度限制
- 建议分段生成大型报告（如年度报告分章节生成）
- L3 案例和 L4 决策记录按需提供，不需要一次性全部加载

### 指令优先级

- 部分平台可能对系统指令有截断或优先级处理
- 如果 AI 行为不符合预期，检查系统指令是否完整加载
- 使用 `SYSTEM-FULL.md` 合并版可减少拼接遗漏

### 数据隐私

- 各平台的数据隐私政策不同，用户需自行评估
- 建议使用脱敏数据
- 敏感数据不要上传到任何第三方平台

## 验证步骤

1. 加载引擎后，对 AI 说："你是谁？" — 预期回答包含"钱喵"和"AI 财务助手"
2. 提供一条测试数据，说："分析这个数据" — 预期触发 Gate-1 流程
3. 检查 Gate-1 输出是否包含规则加载清单和处理计划
4. 检查最终产出是否包含 Gate-2 校验结果（规则扫描 + 独立审查）
