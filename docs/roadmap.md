# 路线图

> 本文档记录项目的未来规划和发展方向。

## 当前状态

**v1.0.0**（2026-08-02）- 初始版本发布。三层分离架构、四层经验包、两级 Gate、独立审查、Instinct 召回、L1 两层加载全部就绪。

## v1.0 已交付

### 架构基础

- 三层分离架构：引擎层 / 配置层 / 数据层
- 四层经验包：L1 规则 + L2 模板 + L3 案例 + L4 决策记录
- 两级 Gate（非阻断）：Gate-1 数据准入 + Gate-2 产出校验
- 引用语法连接四层经验包
- 纯约定扫描（无 pack.yml）

### 引擎能力

- L1 规则两层加载：core（始终加载）+ context（关键词触发）
- 独立审查 agent（REVIEWER）：预报告门控四问 + 误报清单 + 五维度审查
- Instinct 直觉经验召回：confidence 分流（自动应用 / 仅提示 / 静默跳过）
- evidence_chain 证据链：6 子节全链路追踪

### 经验包

- water-soe-finance：33 条规则、7 个模板、15 个案例、4 条 instinct
- _template：空白经验包模板

### 工具

- init_pack.py：创建经验包
- validate_pack.py：校验经验包
- scan_pack.py：安全扫描（prompt injection 检测）

## 规划方向

### 短期

- **千帆平台实跑验证**：在千帆大模型平台上完整运行 v1.0，验证七阶段流水线
- **更多行业经验包**：基于 water-soe-finance 的经验，开发制造业、电力等行业经验包
- **工具增强**：validate_pack.py 增加 L1 core/context 结构校验

### 中期

- **技能扩展**：格式转换（CSV/Excel/PDF 互转）、对话转案例（自动整理为 L3）、财经新闻每日看
- **批量处理**：支持多月份批量分析、多公司对比分析
- **经验包市场**：社区共享经验包的标准化流程

### 长期

- **多平台适配**：更多 AI 平台的适配器
- **可视化看板**：分析结果的可视化呈现
- **自动化流水线**：定时触发、自动采集、自动入库的端到端流程

## 版本规划

| 版本 | 方向 | 状态 |
|------|------|------|
| v1.0.x | 稳定性和工具增强 | 进行中 |
| v1.1 | 更多行业经验包 | 规划中 |

> 路线图会根据实际使用反馈动态调整。
