### AI 推理步骤
- 步骤 1：计算水务核心指标
  - 产销差率 = 产销差量/供水量 = 110/520 = 21.15%
  - 水费回收率 = 水费收入/应收水费 = 1168.50/1298.33 = 90.0%
  - 环比变动：供水量 +5.05%、售水量 -2.38%、漏损量 +46.67%
- 步骤 2：计算财务衍生指标
  - 运营成本占收比 = 营业成本/营业收入 = 1085/1320 = 82.20%
  - 折旧率（月度）= 本期折旧额/固定资产原值 = 21/12000 = 0.175%
  - 借款利率（月度）= 利息支出/借款余额 = 15/3000 = 0.50%
  - 营业利润同比变动 = (140-255)/255 = -45.10%
- 步骤 3：执行勾稽校验
  - 供水量 - 售水量 = 产销差量 → 520 - 410 = 110 ✓
  - 售水量 × 综合水价 = 水费收入 → 410 × 2.85 = 1168.50 ✓
  - 营业收入 - 营业成本 - 期间费用 = 营业利润 → 1320 - 1085 - 95 = 140 ✓
  - 分片区合计 = 售水量 → 180 + 150 + 80 = 410 ✓
- 步骤 4：识别偏差超阈值科目
  - 产销差率 21.15% 超 15% 阈值 → [L1:nrw-variance] Warn
  - 运营成本占收比 82.20% 超 75% 阈值 → [L1:operating-cost-ratio] Warn
  - 折旧率 0.175% 低于 2% 下限 → [L1:depreciation-asset-match] Warn
  - 借款利率 0.50% 低于 2% 下限 → [L1:loan-interest-match] Warn
  - 财政补贴实际为 0 vs 预算 50 万 → [L1:subsidy-income-check] Info
- 步骤 5：按片区分解售水量
  - 城东片区 180 万m³（占 43.90%）
  - 城西片区 150 万m³（占 36.59%）
  - 城南片区 80 万m³（占 19.51%）
  - 合计 410 万m³ ✓
- 步骤 6：生成分析建议
  - 产销差率持续攀升（11.46%→15.15%→21.15%），建议立即开展管网检漏和分区计量排查
  - 成本增速远超收入增速，建议按科目分解成本变动，定位主要增长项
  - 水费回收率下滑，建议加强应收账款管理，分析欠费用户结构
  - 折旧率和借款利率偏低，建议核查折旧政策和借款结构（注意月度/年度口径差异）
  - 财政补贴未到位，建议跟进拨付进度
